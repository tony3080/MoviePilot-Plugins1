# 签到助手

MoviePilot V2 插件，统一执行什么值得买签到和 Chiphell 登录保活。

## 功能

- 通过 MoviePilot `PlaywrightHelper` 调用 CloakBrowser。
- 两个站点可独立启用并配置 Cron。
- 支持配置保存后立即执行一次、结果通知和历史记录。
- Cookie 只保存在插件配置中，不写入日志或历史。

## 配置

1. 从已登录浏览器复制完整 Cookie 请求头。
2. 分别粘贴到对应站点配置。
3. 勾选“立即运行一次”并保存配置，确认通知结果正常后再启用定时任务。

插件仅提供 MoviePilot 配置弹窗，不注册左侧导航或独立详情页面。

Chiphell 当前实现为访问论坛页并验证登录态、读取可见积分，属于登录保活，不调用不存在的独立签到接口。
