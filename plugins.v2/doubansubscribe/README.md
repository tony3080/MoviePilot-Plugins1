# 豆瓣订阅助手

插件 ID：`DoubanSubscribe`

从用户填写的 RSS 地址读取电视剧条目，取得豆瓣详情中的总集数，匹配 TMDB 作品与季度，并创建 MoviePilot 订阅。

## 工作流程

1. 解析 RSS 2.0 或 Atom 条目，优先从豆瓣链接提取 `subject` ID。
2. 通过 MoviePilot 的豆瓣接口读取详情，先按国家或地区分为国产剧、欧美剧、日韩剧或其他地区，并按设置过滤。
3. 豆瓣未明确声明总集数时停止处理该条目。
4. 同时生成完整标题和“基础标题 + 季号”候选，检索并按固定安全阈值评分 TMDB 结果。
5. 创建订阅时将豆瓣总集数写入 `total_episode` 和 `lack_episode`，并设置 `manual_total_episode=1`。
6. 创建后重新读取数据库，确认集数和锁定标记均已保存。
7. 受管订阅完成后否决 MoviePilot 的自动删除，将卡片改为暂停并等待设定的确认天数。
8. 到期后重新读取豆瓣：总集数增加时更新缺失集、恢复订阅并立即搜索一次；总集数不变时将订阅总集数改为 100、保持暂停并交由用户处理。

锁定使用 MoviePilot 自身的“手动修改过总集数”字段。MoviePilot 后续刷新元数据时会保留该总集数，不会用 TMDB 集数覆盖。要求 MoviePilot `2.15.0` 或更高版本。

## 配置

- `RSS 地址`：每行一个 `http` 或 `https` 地址，默认示例为 `http://192.168.110.31:9150/rsshub/hot_tv`。
- `执行周期`：五段 Cron，默认每 6 小时执行一次。
- `每个 RSS 最大条目数`：单次从每个地址处理的上限，默认 50。
- `确认完成天数`：订阅完成并暂停后，等待多少天复查豆瓣总集数，默认 7 天。
- `需要订阅的剧集类型`：可多选国产剧、欧美剧、日韩剧和其他地区，默认全部。
- `RSS 使用代理`：仅影响 RSS 请求；内网 RSS 地址通常不要开启。

插件会保留最近 500 条处理记录。成功创建或已经存在的条目会去重；失败和歧义条目会在后续运行中重试。

## 安全边界

- 不使用 TMDB 集数代替豆瓣总集数。
- 豆瓣总集数缺失、TMDB 得分不足或候选过于接近时，不创建订阅。
- 仅接管本插件以“豆瓣订阅助手”用户创建的订阅；相同 `tmdb_id + season` 的用户原订阅不会被修改。
- 豆瓣复查暂时失败时不会改成 100，而是保持卡片并在 1 天后重试。

详细匹配算法与风险分析见仓库根目录的 `豆瓣接口与TMDB电视剧匹配设计.md`。
